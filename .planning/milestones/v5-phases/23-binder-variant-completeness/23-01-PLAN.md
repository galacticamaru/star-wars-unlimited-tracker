| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-23-01-02 | Information Disclosure | `getUserTradeData` and `/api/binder/wants` | mitigate | All DB mutations include `eq(table.userId, session.user.id)` — IDOR blocked at query level (V4 ASVS). Existing auth gate in route returns 401 before touching DB. No change in this plan. |
| T-23-01-03 | Tampering | Schema migration — multi-step PK swap | mitigate | Hand-written SQL with explicit statement order (add column → populate from Normal printing → delete unmapped → NOT NULL → FK → drop old PK + column → add new PK).
