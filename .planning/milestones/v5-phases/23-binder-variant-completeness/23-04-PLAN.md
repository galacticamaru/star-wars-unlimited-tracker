**A) Create `src/db/queries/collection.ts`** (new file) exporting `getOwnedCardDefinitions(userId: number)`. This query:

1. Fetches all rows from `userCollections` where `userId = userId AND count > 0`, joined to `cardDefinitions` to get `name`, `subtitle`, `type`. Capture `cardDefinitionId` and the per-definition `count`.
2. For each owned card definition, fetch ALL `cardPrintings` rows (not just owned variants — the Sheet may want to show "Trading: 2" rows even for unowned variants if the user has an active offering, but per D-15 the Sheet shows ONLY owned printings; per the manual-wants flow the chip selector shows ALL printings so the user can want a variant they don't own yet). Strategy: do one batched fetch of all printings for the set of `cardDefinitionId`s using `inArray`.
3. Also fetch `userPrintingCollections` rows for this user joined to those printings — to compute per-printing `ownedCount`.
4. Also fetch `userTradeOfferings` rows for this user joined to those printings — to compute per-printing `tradeQuantity` (lets the tile's quantity badge show a "trading" count without a separate fetch).
5. Group results in memory: for each owned card definition, build a `printings: Array<{ id, variantType, ownedCount, tradeQuantity }>` and compute `bestArtUrl` using `selectBestVariantArtUrl` from `@/lib/catalog/select-best-variant`. Pass `variants` map of `{ [printingId]: ownedCount }` and `printingArtMap` of `{ [printingId]: { variantType, frontArtUrl } }`.
