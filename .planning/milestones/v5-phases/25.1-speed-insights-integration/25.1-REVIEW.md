## Warnings

### WR-01: Suspense boundaries missing fallback props

**File:** `src/app/layout.tsx:42` and `src/app/layout.tsx:46`
**Issue:** Both `<Suspense>` wrappers — around `<NavBar />` and around `<CurrencyProvider>` — omit the `fallback` prop. React renders `null` when no fallback is provided, so users see a blank gap during the suspend window. This is especially visible on slow connections when `NavBar` is suspended (e.g., if it uses async data). React also emits a warning in strict development mode when a Suspense boundary has no fallback.
**Fix:**
```tsx
// Line 42 — NavBar boundary
<Suspense fallback={null}>
  <NavBar />
</Suspense>

// Line 46 — CurrencyProvider boundary
<Suspense fallback={null}>
  <CurrencyProvider>
    {children}
  </CurrencyProvider>
</Suspense>
```
Passing `fallback={null}` is explicit and suppresses the React warning. A skeleton or spinner is preferable if visual continuity matters.
