## Sample Rate

| Option | Description | Selected |
|--------|-------------|----------|
| 100% | Default. Every pageview sampled. No cost/noise reason to sample at this scale. | ✓ |
| 50% | Track half of all pageviews. Useful for high-traffic apps — overkill here. | |
| Custom value | Set a specific rate between 0 and 1. | |

**User's choice:** 100% (default)
**Notes:** No `sampleRate` prop needed — omit entirely to accept the library default.

---

## Route Exclusion

| Option | Description | Selected |
|--------|-------------|----------|
| No exclusions | Track all pages. No admin/staging routes that would pollute metrics. | ✓ |
| Exclude specific routes | Add beforeSend hook to skip named routes. | |

**User's choice:** No exclusions
**Notes:** API routes are excluded automatically by the library. All page routes tracked.

## Debug Panel in Dev

| Option | Description | Selected |
