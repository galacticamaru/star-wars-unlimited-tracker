<objective>
Make the deck builder toolbar fit narrow phone screens without overflow or clipping by restructuring it into a two-row flex-col layout on mobile: Row 1 holds the deck name input (full width), Row 2 holds shortened tab labels plus icon-only Export and Back buttons. Desktop keeps the existing single-row layout unchanged.

This plan implements requirement MOBILE-03 and locked decisions D-06, D-07, D-08.

Purpose: The current toolbar is a single flex row — on screens below 480px, the name input, three tab buttons with long labels ("Deck List", "Add Cards", "Want List"), export button with text, and back button with text all compete for width, causing overflow or text truncation. The two-row pattern is well-established in this codebase (existing `flex flex-col md:flex-row` patterns throughout).

Output: ~15 line diff in `deck-builder.tsx` toolbar section (lines 310–364) plus conversion of the MOBILE-03 Wave 0 stub to a passing test. No new packages.
