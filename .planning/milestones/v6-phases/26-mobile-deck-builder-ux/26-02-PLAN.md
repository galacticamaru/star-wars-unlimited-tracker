<objective>
Make the deck builder usable on mobile by (a) wiring a bottom Sheet that exposes the full DeckSidebar (cost curve, aspect breakdown, validity, Save buttons), (b) replacing the obsolete mobile `hoveredCard` bar with an always-visible sticky summary bar that doubles as the Sheet trigger, (c) hiding the inline DeckSidebar on mobile via `hidden md:flex`, (d) adjusting the root container height formula to `dvh`-on-mobile / `svh`-on-desktop so the virtual keyboard does not cut off Save buttons, and (e) making DeckSidebar's root class context-aware so it renders correctly inside SheetContent.

This plan implements requirements MOBILE-01 and MOBILE-04, and locked decisions D-01, D-02, D-03, D-04, D-05, D-11, D-12.

Purpose: Without this plan, the existing inline DeckSidebar (`w-80 flex h-full`) covers the full deck list on phones, the Save buttons are unreachable, and the page height is not keyboard-aware. The sticky bar pattern is already production-proven in `mobile-filter-sheet.tsx`.

Output: A mobile-usable DeckBuilder with sticky bar + bottom Sheet, desktop layout untouched, no new dependencies, ~50 line diff in `deck-builder.tsx` plus one class change in `deck-sidebar.tsx`.
</objective>
