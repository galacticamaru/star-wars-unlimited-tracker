<objective>
Establish the storage + typing foundation for the public trade note. Add a nullable `trade_note` column to the Drizzle `user` table, declare `tradeNote` as a Better Auth `additionalField` (`required: false`) so it rides the existing `authClient.updateUser` write path (D-10), type it on the client via `inferAdditionalFields`, and apply the schema change to the live Neon database.

Purpose: Every downstream surface (the modal write path in Plan 03, the public read path in Plan 04) depends on this column existing both in `schema.ts` (types) and in the live DB (runtime). This plan removes the single genuine risk this phase carries — the additionalField/column pairing (RESEARCH Pitfall 1).

Output: `trade_note` column live in Neon, `tradeNote` additionalField declared and typed end-to-end, one committed migration file.
</objective>
