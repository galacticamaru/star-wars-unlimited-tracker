  <action>
**Pre-migration row count check.**
Before running the migration SQL, record the current row counts as a baseline:

Run this SQL (use the DATABASE_URL from .env):
```sql
SELECT COUNT(*) as before_migration FROM user_collections WHERE trade_quantity > 0;
```

If the result is 0, the migration is a no-op (no existing trade data to migrate) — note this and proceed.
If the result is > 0, note the count — the migration must produce the same number of rows in `user_trade_offerings`.

**Run the data migration SQL (D-03).**
This INSERT SELECT migrates existing `trade_quantity > 0` rows from `user_collections` to `user_trade_offerings`, treating them as Normal variant offerings:

```sql
INSERT INTO user_trade_offerings (user_id, card_printing_id, quantity)
SELECT uc.user_id, cp.id, uc.trade_quantity
FROM user_collections uc
JOIN card_printings cp ON cp.card_definition_id = uc.card_definition_id
WHERE cp.variant_type = 'Normal'
  AND uc.trade_quantity > 0;
```

Run this via `psql` using the DATABASE_URL connection string:
```
psql "$DATABASE_URL" -c "INSERT INTO user_trade_offerings (user_id, card_printing_id, quantity) SELECT uc.user_id, cp.id, uc.trade_quantity FROM user_collections uc JOIN card_printings cp ON cp.card_definition_id = uc.card_definition_id WHERE cp.variant_type = 'Normal' AND uc.trade_quantity > 0;"
```

If `psql` is not available, use the Neon console SQL editor or a Node.js inline script with the Neon driver:
```javascript
// One-time migration script
const { neon } = require('@neondatabase/serverless');
const sql = neon(process.env.DATABASE_URL);
const result = await sql`
  INSERT INTO user_trade_offerings (user_id, card_printing_id, quantity)
  SELECT uc.user_id, cp.id, uc.trade_quantity
  FROM user_collections uc
  JOIN card_printings cp ON cp.card_definition_id = uc.card_definition_id
  WHERE cp.variant_type = 'Normal' AND uc.trade_quantity > 0
`;
console.log('Migration complete:', result);
```

**Post-migration row count check.**
After running the SQL, verify:
```sql
SELECT COUNT(*) as after_migration FROM user_trade_offerings WHERE quantity > 0;
```

The row count in `user_trade_offerings` should equal or exceed the `before_migration` count (it could exceed it if a card_definition has multiple Normal printings, but in practice each card has one Normal printing).
