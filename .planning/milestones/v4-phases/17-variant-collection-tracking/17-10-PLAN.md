Wait for the seed to complete. The seed logs `setsTotal`, `setsProcessed`, and `cardsUpserted`. Confirm:
- Exit code 0
- `setsProcessed` equals `setsTotal` (no sets failed)
- `cardsUpserted` is non-zero

After seeding, verify SEC-030F now exists in the DB by running this SQL against the Neon DB (via `psql $DATABASE_URL` or Neon console):

```sql
SELECT cp.id, cp.collector_number, cp.variant_type, cp.card_definition_id,
       cd.swudb_id AS definition_swudb_id, cd.name
FROM card_printings cp
JOIN card_definitions cd ON cd.id = cp.card_definition_id
WHERE cp.set_code = 'SEC'
  AND cd.swudb_id = 'SEC-030'
ORDER BY cp.variant_type;
```
