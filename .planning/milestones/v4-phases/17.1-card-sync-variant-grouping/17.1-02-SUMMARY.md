## Deviations from Plan

During human checkpoint spot-check, a React duplicate key error appeared in the catalog (`key="905-catalog"`). Root cause: the new in-memory (Name, Subtitle) grouping correctly links all variants to one card_definition_id — but some IBH set cards (e.g. "Admiral Piett - In Command Now") have two distinct Normal printings at different collector numbers that the grouping merged. Before the re-seed, each Normal had its own card_definition_id so the `${card.id}` key was accidentally unique. After re-seed, `card.id` (card_definition_id) is shared across multiple printings of the same logical card, breaking React key uniqueness.

Fixed by switching `CardGrid` React key from `${card.id}-${mode}` to `${card.collectorNumber}-${mode}` — `collectorNumber` is the unique key for `card_printings`.
