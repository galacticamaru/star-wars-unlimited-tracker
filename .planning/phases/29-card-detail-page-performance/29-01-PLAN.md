<objective>
Split `getCardByPrinting` into a cacheable public `getCardDefinition(setCode, cardNumber)` query (no user joins) and add per-user caching to `getSameSetPrintingsWithCounts`. Remove the legacy collection-hydration block from the card detail page. This is the TTFB/LCP foundation for PERF-10 (D-01, D-02, D-03).

Output: Cached `card-detail.ts` query functions; `page.tsx` updated to call the new function with the legacy hydration block removed.
</objective>
