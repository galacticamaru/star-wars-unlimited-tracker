<objective>
Close DEBT-04: ensure the catalog owned-count overlay is never stale after a user edits owned counts on a card detail page and returns to the catalog.

The standard React-remount path is already handled by the existing `useEffect([isAuthenticated])` collection re-fetch in `CatalogClient` (D-06 — verified in source: lines 72-81). A `pageshow` listener that re-fetches on `event.persisted` for authenticated users covers this gap.

Purpose: Eliminate the stale owned-count overlay that mobile users see when using the native back button after editing collection counts.

Output: One new `useEffect`-registered `pageshow` listener in `catalog-client.tsx`.
</objective>
