# Plan 19-01: Update VariantFilter and State Tracking

**Goal**: Add missing variant types to the filter component and ensure they are correctly tracked in Catalog, Deck Builder, and Public Binder.

## Requirements
- **REQ-FILTER-01**: User can filter cards by all available variant types (Normal, Foil, Hyperspace, Hyperspace Foil, Showcase, Prestige, Serialized).

## Proposed Changes

### 1. `src/components/catalog/variant-filter.tsx`
- Add `"Foil"` and `"Hyperspace Foil"` to the `VARIANT_OPTIONS` array.
- This will automatically show them in the UI.

### 2. `src/components/catalog/catalog-client.tsx`
- The `handleClearAll` function already resets `selectedVariants` to `['Normal']`.
- Verify if any other changes are needed for state sync (it seems okay as it uses `nuqs`).

### 3. `src/components/binder/public-binder-client.tsx`
- Add `selectedVariants` state using `nuqs` (same as `CatalogClient`).
- Pass `selectedVariants` and `onVariantsChange` to `SidebarFilters`.
- Ensure `selectedVariants` is passed to the `filterCards` function in the `useMemo` block.
- Add `selectedVariants` to the `useMemo` dependency array.

## Verification Plan

### Automated Tests
- None required for this UI-only change, but can manually verify state in URL.

### Manual Verification
1. Open Catalog. Verify "Foil" and "Hyperspace Foil" appear in the Variant filter.
2. Select "Foil". Verify cards with `variantType === 'Foil'` are shown.
3. Open Deck Builder -> Add Cards tab. Verify the same filters are available and functional.
4. Open a Public Binder (e.g., `/binder/user`). Verify filters work there too.
