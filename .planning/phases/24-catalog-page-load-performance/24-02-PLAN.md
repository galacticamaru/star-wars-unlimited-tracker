<objective>
Implement search-input debounce in `CatalogClient` to satisfy PERF-01: filter changes reflect in ≤200ms without mid-keystroke re-renders.

Purpose: Currently every keystroke in the search input writes immediately to nuqs URL state, which triggers `filterCards` re-computation and a full grid re-render on each character. The grid has 1000+ cards — re-rendering on every keystroke creates input lag. Per D-01, a 150ms debounce eliminates this thrash while remaining imperceptible to the user.

Output: `CatalogClient` with local `searchInput` state, a 150ms useEffect debounce wrapping the nuqs `setSearch` setter, an updated `handleClearAll` that resets local state, and `SidebarFilters` receiving `searchInput`/`setSearchInput` instead of `search`/`setSearch`.
</objective>
