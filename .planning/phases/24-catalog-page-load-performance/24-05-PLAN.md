`export const dynamic = 'force-dynamic'`:
- Per-route export that forces dynamic (non-prerendered) execution
- Standard escape hatch for routes that read request data (headers, cookies, query params) at runtime
- Per RESEARCH.md Pitfall 6: under `cacheComponents: true`, GET Route Handlers follow the prerendering model unless explicitly opted out
- Source: node_modules/next/dist/docs/01-app/03-api-reference/05-config/02-route-segment-config/dynamic.md

Build error to watch for:
- `Uncached data was accessed outside of <Suspense>` — indicates the prerendering model is trying to call a route handler that reads runtime APIs without an opt-out
- Resolution: add `export const dynamic = 'force-dynamic';` at the top of the offending route file

- `src/app/api/cron/sync-cards/route.ts` — reads `request.headers.get('authorization')` at runtime; currently has NO `dynamic` export. May need opt-out under cacheComponents.
