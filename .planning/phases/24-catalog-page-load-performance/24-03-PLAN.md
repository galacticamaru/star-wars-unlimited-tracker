<objective>
Implement CardGrid virtualization with `@tanstack/react-virtual` (PERF-01) and image priority threading for the first two visible rows (PERF-03).

Purpose: The unfiltered catalog has 1000+ card definitions × N variant rows. Rendering all of them to the DOM causes a multi-second initial paint and sluggish scroll. Per D-03, windowed rendering via `useVirtualizer` reduces DOM nodes to only those visible in the viewport (plus an overscan buffer). Per D-10, the first 22 cards (approximately two rows at xl/11 columns) load with `<Image priority>` so the above-fold content appears before below-fold images compete for bandwidth.

Output: New `@tanstack/react-virtual` dependency; `CardGrid` refactored to use `useVirtualizer` with breakpoint-aware column count and absolute-positioned rows; `CardItem` accepts a new `priority` prop forwarded to `<Image>`; `CatalogClient` creates a ref to the `<main>` scroll container and passes it to `CardGrid`; Wave 0 test stubs become real GREEN assertions.
</objective>
