## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding (`gap-1`, `p-1`) |
| sm | 8px | Button gaps, tight row spacing (`gap-2`, `p-2`) |
| md | 16px | Default element and toolbar padding (`p-4`, `gap-4`) |
| lg | 24px | Section padding inside Sheet content |
| xl | 32px | Layout gaps between builder sections |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- **Touch targets:** All interactive +/- buttons and action buttons use `h-11 w-11` (44px). This applies at ALL screen sizes — permanent upgrade, not responsive. Source: CONTEXT.md D-09, REQUIREMENTS.md MOBILE-02.
- **Sticky summary bar:** `h-14` (56px) fixed height. Provides sufficient tap area and visual weight against the builder content above.
- **Sheet max-height:** `max-h-[80dvh]` — not an 8-point value, but a viewport unit dictated by the bottom-sheet UX pattern (D-02).
- **Root container height:** `h-[calc(100dvh-56px)] md:h-[calc(100svh-56px)]` — keyboard-safe on mobile (dvh), stable on desktop (svh). Source: CONTEXT.md D-12.

## Interaction Contracts

### Sticky Summary Bar (MOBILE-01 — D-01)

- **Visibility:** `md:hidden` — renders only below the `md` (768px) breakpoint
- **Positioning:** `fixed bottom-0 left-0 right-0 z-50` — always visible above builder content
- **Height:** `h-14` (56px)
- **Background:** `bg-white border-t` — continuous with toolbar styling
- **Content layout:** `flex items-center gap-4 px-4`
- **Content:** `<Badge>` (Legal or Illegal) + `<span className="text-sm text-muted-foreground">` with text `"{totalMain}/50 main · {sideboardTotal}/10 SB"`
- **Tap behaviour:** Entire bar is the `SheetTrigger` — tapping anywhere on it opens the Sheet
- **SheetTrigger pattern:** `<SheetTrigger render={<button className="md:hidden fixed bottom-0 ...w-full" />}>` — use `render` prop (NOT `asChild`, which is the Radix pattern). Source: CONTEXT.md D-01, RESEARCH.md Pattern 5, Pitfall 6.

### Bottom Sheet (MOBILE-01 — D-02, D-04)

- **Trigger:** Sticky summary bar tap
- **Side:** `side="bottom"`
- **Height constraint:** `className="max-h-[80dvh] overflow-y-auto"` on `SheetContent`
- **Contents:** `DeckSidebar` component (all existing props passed through), wrapped in `<div className="w-full">` to constrain the sidebar's `w-80` to full sheet width
- **Portal:** `SheetPortal` (already inside `SheetContent`) renders to `document.body` — the `<Sheet>` wrapper element must be placed OUTSIDE the `overflow-hidden` flex container to avoid z-index/transform traps. Source: RESEARCH.md Pitfall 1, CONTEXT.md D-04.
- **Save buttons location:** "Save as Draft" and "Complete Deck" are inside `DeckSidebar` — accessible inside the Sheet only on mobile. Not duplicated elsewhere. Source: CONTEXT.md D-11.

### Desktop Inline Sidebar (MOBILE-04 — D-05)

- **Visibility:** `hidden md:flex` — hidden on mobile, visible on desktop
- **No other desktop changes** — zero regression at md breakpoint and above

### Mobile Toolbar (MOBILE-03 — D-06, D-07, D-08)

- **Mobile layout:** `flex flex-col` — two rows
  - Row 1: deck name input, full width (`w-full`)
  - Row 2: short-label tab group (`"Deck"` / `"Cards"` / `"Wants"`) + icon-only Back button + icon-only Export button (Download icon only)
- **Desktop layout:** `flex flex-row justify-between items-center` — single row (current layout preserved)
- **Tab label switching:** `<span className="hidden md:inline">Deck List</span><span className="md:hidden">Deck</span>` pattern inside each tab Button
- **Export button mobile:** `<Download className="w-4 h-4" />` with no text label. `<span className="hidden md:inline ml-2">Export</span>` wraps the text. Source: CONTEXT.md D-08, RESEARCH.md Pattern 3 (code examples).
- **Back button mobile:** Icon-only `<ArrowLeft className="w-4 h-4" />` with no text. `<span className="hidden md:inline ml-1">Back</span>` wraps the text.

### Touch Targets (MOBILE-02 — D-09, D-10)

- **Deck list +/- buttons:** Change from `h-8 w-8` (`size="icon"`) to `h-11 w-11` via `className` override. Applies at ALL screen sizes — not responsive.
- **"Move to SB" / "Move to Main" buttons:** Same upgrade — `h-11 w-11`.
- **Catalog overlay +/- buttons** (`card-item.tsx`): Change `p-1` to `min-h-[44px] min-w-[44px] flex items-center justify-center`. The icon size (`w-4 h-4`) remains unchanged.
- **Rationale:** WCAG 2.5.5 and Apple HIG minimum 44px touch target. Source: REQUIREMENTS.md MOBILE-02.

### Height Formula (D-12)

- **Root container:** `h-[calc(100dvh-56px)] md:h-[calc(100svh-56px)]`
  - Mobile: `dvh` (dynamic viewport height) — shrinks when virtual keyboard appears, preventing Save button from being hidden
  - Desktop: `svh` (small viewport height) — stable, does not reflow on scroll
  - Replace current `h-[calc(100svh-56px)]` at `deck-builder.tsx` line 307

### hoveredCard Bar Removal (D-03)

- **Remove:** Lines 606-621 in `deck-builder.tsx` (the `hoveredCard && (...)` `fixed bottom-0` conditional bar)
- **Keep:** `hoveredCard` state, `setHoveredCard` handlers, and the desktop preview panel (lines 385-397, `hidden md:block`) — the desktop feature is preserved
- **Reason:** The sticky summary bar replaces the mobile hoveredCard bar. The desktop preview remains because D-03 specifies "hoveredCard preview feature is removed from mobile" only.
