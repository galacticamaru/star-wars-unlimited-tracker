<objective>
Upgrade all touch-relevant interactive buttons in the deck builder to meet the 44×44px minimum touch target required by WCAG 2.5.5 and Apple HIG. This means: deck list row +/- buttons (currently `h-8 w-8` = 32px) become `h-11 w-11` = 44px; "Move to SB" / "Move to Main" buttons (currently `h-8`) become `h-11`; and the catalog overlay selector-mode +/- buttons (currently `p-1`, ~24px effective) become `min-h-[44px] min-w-[44px] flex items-center justify-center`.

This plan implements requirement MOBILE-02 and locked decisions D-09 and D-10. The upgrade is permanent (applies at all screen sizes, not responsive) per D-09.

Purpose: Without 44px targets, mobile users mis-tap adjacent +/- buttons on dense deck rows. The change is pure CSS — no behaviour modification, no API change, no new components.

Output: ~6 className edits across `deck-builder.tsx` (lines 530, 531, 532-540, 585, 586, 587-594) and `card-item.tsx` (lines 138-149, 154-166). The MOBILE-02 Wave 0 stub in `card-item.deck.test.tsx` is converted to a passing test, and the MOBILE-02 stub in `deck-builder.test.tsx` is also converted.
</objective>
