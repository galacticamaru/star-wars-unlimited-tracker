  <action>
Run the orphan-check SQL query against the live database. Use whichever DB access method is available:

**Option A — psql (if installed):**
```bash
psql "$DATABASE_URL" -c "
SELECT COUNT(*) AS orphaned_variants
FROM card_printings cp
WHERE NOT EXISTS (
  SELECT 1 FROM card_printings cp2
  WHERE cp2.card_definition_id = cp.card_definition_id
    AND cp2.set_code = cp.set_code
    AND cp2.variant_type = 'Normal'
)
AND EXISTS (
  SELECT 1 FROM card_printings cp3
  WHERE cp3.set_code = cp.set_code
    AND cp3.variant_type = 'Normal'
    AND cp3.collector_number != cp.collector_number
);
"
```

**Option B — inline script (always works):**
Create a one-shot Node.js script `scripts/orphan-check.ts` that runs the query via the project's Drizzle `db` instance and prints the result:

```typescript
import { db } from '@/db';
import { cardPrintings } from '@/db/schema';
import { sql } from 'drizzle-orm';

const result = await db.execute(sql`
  SELECT COUNT(*)::int AS orphaned_variants
  FROM card_printings cp
  WHERE NOT EXISTS (
    SELECT 1 FROM card_printings cp2
    WHERE cp2.card_definition_id = cp.card_definition_id
      AND cp2.set_code = cp.set_code
      AND cp2.variant_type = 'Normal'
  )
  AND EXISTS (
    SELECT 1 FROM card_printings cp3
    WHERE cp3.set_code = cp.set_code
      AND cp3.variant_type = 'Normal'
      AND cp3.collector_number != cp.collector_number
  )
`);
console.log('Orphaned variants:', result.rows[0].orphaned_variants);
```

Run it with `npx tsx scripts/orphan-check.ts` (set NODE_TLS_REJECT_UNAUTHORIZED=0 if needed).
