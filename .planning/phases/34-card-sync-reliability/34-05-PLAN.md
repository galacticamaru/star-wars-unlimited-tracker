<objective>
Replace the quick-add route's silent skip with a reported one (D-16), and carry the report through to the collection page's success banner.

`starter-deck/route.ts:60-63` currently drops any collector number it cannot resolve with the comment "skip silently (could be a data gap)", then returns a `cardsAdded` count that looks like a complete success. 34-04 removes the underlying data gap; this plan removes the ability for that gap to hide again.

Purpose: the phase's governing principle applied to the one user-facing surface it touches — partial work must never report itself as complete. Keep adding what resolves, because a partial add still beats a failed one, but say so.
Output: an additive response contract, a route test, and updated banner copy.
</objective>
